# random-code-snippets

Small, realistic codebases with problems in them. Read the code, find what's wrong, explain what it breaks,
and fix it.

| Folder | Topic | Stack |
|---|---|---|
| [`01-google-login`](01-google-login) | Sign in with Google (OAuth 2.0 and OpenID Connect) | NestJS, React |
| [`02-orders-dashboard`](02-orders-dashboard) | An orders page that slows down at sale time | NestJS, MongoDB |
| [`03-product-permissions`](03-product-permissions) | Who can see and change products | NestJS, MongoDB |
| [`04-otp-login-and-tokens`](04-otp-login-and-tokens) | OTP login, access tokens and refresh tokens | NestJS, Redis |

Each folder has a README with the scenario, the files and the task. The code is meant to be read, not run:
services it depends on but doesn't include are described in that README.
